# Paper source

`main.tex` is the source of **“What Makes a Generalist Robot Policy? A Study of
Models, Tasks, and Data for Low-Cost Bimanual Manipulation.”** It is the source
of truth for the embodiment, eight benchmark tasks, experiment matrix, and
reported metrics implemented by this repository.

The manuscript still contains explicit draft placeholders. Keep those visible
until the corresponding figures, artifact identifiers, sample counts, and
results are finalized.
